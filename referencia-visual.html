🔓 Colunas com MDX Habilitado — PKs e FKs
Colunas chave detectadas que podem ter MDX desabilitado para reduzir overhead do servidor OLAP
⚠️
Atenção antes de desabilitar MDX
Desabilitar MDX em colunas remove a propriedade IsAvailableInMDX = true no modelo tabular. Isso impede que a coluna apareça em clientes MDX (Excel via OLAP, Report Builder, SSRS legado) — consultas DAX e Power BI Web não são afetadas.
Ganho: Reduz o tamanho das hierarquias de atributos geradas automaticamente, diminui RAM e acelera o tempo de discovery do modelo. Ideal para PKs/FKs inteiras que nunca aparecem em slicers ou visuais.
# Coluna Tipo Detectado Tipo de Dado Cardinalidade Tamanho MDX Ativo Ação
💡 Como aplicar no Tabular Editor: Selecione a coluna → propriedade IsAvailableInMDX → altere para False. Em XMLA, adicione a annotation "IsAvailableInMDX": false na coluna. Processe o modelo após salvar.
